

# Football Mobile

Football Mobile is a football game designed out of frustration with other mobile football games like FIFA Mobile and PES Mobile. We wanted to create a game that truly delivers the ultimate football experience without the limitations and frustration of pay-to-win mechanics.

## Features
- **Customizable Teams**: Build and manage your dream team.
- **No Pay-to-Win**: Enjoy the game without any microtransactions or unfair advantages.
- **Available for Web & Android**: Play on both mobile platforms with full control.

## Why Football Mobile?
We know that mobile football games can be frustrating due to their over-reliance on in-app purchases. Football Mobile is built with fairness in mind, giving all players an equal opportunity to succeed based on skill, not spending.
